# laraferrarialvarez-herramientas_basicas_para_analisis_datos_utnba_ferrari_alvarez_lara
Trabajo final del curso "Herramientas básicas para el análisis de datos" dictado por el centro de e-learning de la Universidad Tecnológica Nacional (UTN)

---
**Objetivos:** 
- Objetivo general: Analizar la evolución y las tendencias de la AOD (Ayuda Oficial para el Desarrollo) brindada a países en el período de 2004 a 2023.
- Objetivos específicos:
* Analizar y limpiar y data set con Python en Colab
* Realizar preguntas de investigación que puedan responderse con el data set con Python en Colab
* Realizar gráficos que ilustren estas respuestas, tanto en Python como el Colab
  
--- 
**Fuente del data set:** Our World in Data

**Enlace al data set:** https://www.google.com/url?q=https%3A%2F%2Fdrive.google.com%2Ffile%2Fd%2F1LIq-EpiwdmaNCnDcf5W1GWnnqC-DrXbE%2Fview%3Fusp%3Dsharing

---
**Herramientas utilizadas:** Google Colab y Power BI

**Librerias de Python utilizadas:** 
* Pandas
* Seaborn
* Matplotlib
* 
---
**Pasos realizados:**

1. Selección e importación del dataset sobre Ayuda Oficial para el Desarrollo (AOD) en Google Colab.
2. Exploración y limpieza de los datos, revisando su estructura, tipos de variables, valores nulos y registros duplicados.
3. Realización del análisis exploratorio mediante análisis univariados, bivariados y trivariados de variables cuantitativas y cualitativas.
4. Desarrollo de visualizaciones y análisis específicos para responder las preguntas de investigación planteadas.
5. Importación de los datos en Power BI y construcción de un dashboard con gráficos e indicadores que resumen los principales resultados.
6. Incorporación de filtros y segmentadores en Power BI para permitir una exploración interactiva de la información.
